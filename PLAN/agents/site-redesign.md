# Agent Brief: site-redesign-and-gallery (Wave A scaffold → Wave C final)

## Hard rules (Xenco Labs non-negotiables — obey without exception)

- Production-quality only. No workarounds. No quick fixes. No mock data. No mock
  fallbacks. If a path can't be made real, it does not ship — it waits.
- Nothing a customer can pay for may map to a delivery you can't actually fulfill.
- Prodigi must be verified in LIVE production mode before any print-to-ship charge is
  possible. Sandbox is not "done."
- Schema-first. Services-layer-always. Do not hardcode prices in the frontend — read
  from Stripe. Do not conflate the two products' data models silently — map them.
- Defer to the running system over any assumption, including the founder's account
  above and including your own training data. Where they conflict, the code wins and
  you flag the conflict.

## Mission

Phase 5 of `PLAN/01-plan.md` — show-don't-tell. As-built is FATAL for a visual
product: `public/` contains only `site.webmanifest`; every style-pack sample is a
`picsum.photos` placeholder (`prisma/seed-style-packs.ts:20-21`), whitelisted in
`next.config.ts` — random stock imagery is live in production today. Fix: real
before/after gallery generated by the product's own engine, hero rebuilt around
real output.

## Blockers you must respect

- Face-swap verdict decides hero framing + copy (swap vs "inspired-by").
- Real-asset generation (5.1) is THE ONLY sanctioned generation-credit spend in this
  program, and it happens in an execution session via the product pipeline/MCPs —
  gated on Phases 1–3 core landing. Founder supplies source photos with usage
  rights for before/after pairs (answer #11 confirms whether any real samples
  already exist in R2).
- **NO video hero.** Still-image product; video misrepresents what's sold. Subtle
  scroll-reveal on real transformation PAIRS only.

## Work items

1. **5.1 Real assets.** ≥1 real engine-generated sample per style variant (49) +
   6–10 hero-grade before/after pairs, stored in R2 under `marketing/`; seeds + DB

2. **5.2 Hero + gallery rebuild.** Hero around one real transformation (static or

## Definition of done

- `grep -rn "picsum" app lib prisma next.config.ts` returns nothing; DB query shows
  zero picsum URLs in StylePack/StyleVariant.
- Production homepage shows ≥6 real before/after pairs within one scroll of the fold.
- OG image is real product output; no stock/mock imagery anywhere on the site.
- Lighthouse mobile performance ≥85 on `/`.
- No video element in the hero.

## Smoke test (lead re-runs)

project's R2 (`marketing/` or user-output keys); Lighthouse run attached; pricing
